# Pressura · 情绪标本

对着麦克风说话、叹气或呐喊，场景中央会从一粒种子长成冰、石或火。声音停下后，它凝结成一件可以 3D 把玩的"情绪标本"：可以在上面种树、浇水、浇汽油、双击敲碎，或者收进画廊。

> 这是"声音特征 → 视觉"的表达映射，不是情绪识别。

## 隐私

- 音频只在浏览器本地分析，不上传、不保存原始录音
- 画廊数据只存在本机 IndexedDB

## 开发

需要 Node 22+（Vitest 5 官方支持 22 / 24 / 26）和本机安装的 Google Chrome（端到端检查用）。

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm run check      # 类型检查 + lint + 单测 + 构建
npm run e2e        # 无头 Chrome 跑端到端场景，截图输出到 .e2e/
```

麦克风需要安全上下文：本地 `localhost` 可以直接用，部署后必须是 HTTPS。

## 声音如何变成材质

- 开场 1.5 秒测环境底噪；之后按"高出底噪多少 dB"计算发声强度（关闭了浏览器的自动增益和降噪）
- 压力只增不减：越响长得越快，低语也会慢慢累积，强突发额外加成
- 压力到 15% 时，根据这段声音定型：
  - 火：响、爆发多、声音偏亮（吼、喊）
  - 冰：轻、平稳、起音少（叹气、低语、闷声）
  - 石：中等响度、起音密集、断断续续（急促的碎碎念）
- 之后只有最近 4 秒持续 3 秒以上明显偏向另一种材质，才会转变
- 安静 3 秒（且已说话 5 秒、压力 ≥ 10%）、手动结束或压力满 100% 时结束

所有阈值集中在 `src/core/audio/tuning.ts`。录制时按 D 打开调试面板，可以看到实时电平、底噪、强度、起音和三种材质的得分，用来真人试音调参。

模拟模式：没有麦克风时可以选冰/石/火风格，按住空格或"按住发声"按钮。

## 目录结构

```
src/
  core/          不依赖 React / three.js 的纯 TS：音频分析、压力模型、情绪签名、处置规则
  scene/         React Three Fiber 场景组件
  ui/            HUD、工具栏等 DOM 界面
  app/           桌面应用外壳：状态机、页面组合
scripts/         端到端检查、测试音频生成
```

`core/` 刻意保持框架无关，将来做 agent 宠物插件时可以直接复用，只需要换一个外壳。
